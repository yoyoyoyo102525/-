## 練習功能

- **練習**：題目隨機排序，選項固定照原本的 ①②③④（跟考試一樣），選了馬上對答案。範圍可選全部、6 個主題（勞基法、職安法規與職災保險、災害預防、職業衛生與職業病、急救、不法侵害與母性保護）、錯題本、還沒練過的題目
- **題庫總覽**：100 題照原本題號排列，正確答案用螢光筆標出來。可以搜尋關鍵字，也可以勾「遮住答案」自我測驗（點題目才顯示答案）
- 答錯的題目自動收進錯題本，之後答對就移出
- 鍵盤：`1`–`4` 作答，`Enter` 下一題
- 練習紀錄存在瀏覽器裡，換電腦或清除瀏覽資料就會不見
