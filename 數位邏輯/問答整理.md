## Ch1 數位邏輯基本概念

### Q1. CMOS 邏輯族，當 V_SS 接地時，1 與 0 的輸入電壓準位分別為？（1-3.1）

**答：0.7 V_DD 以上為 1，0.3 V_DD 以下為 0**

| | 邏輯 1 | 邏輯 0 |
|---|---|---|
| CMOS（V_SS 接地） | **0.7 V_DD 以上** | **0.3 V_DD 以下** |
| V_DD = 5 V 時 | 3.5 V 以上 | 1.5 V 以下 |
| TTL（對照） | 2.0 V 以上 | 0.8 V 以下 |

- 0.3 V_DD ～ 0.7 V_DD 之間不允許
- 選項常把 TTL 的 2.0 V／0.8 V 放進來混淆
- 有些書寫成 ⅔ V_DD、⅓ V_DD，以課本為準

### Q2. V_SS 是什麼？（1-3.1）

**答：CMOS 的負電源腳，通常接地（0 V）**

| | 正電源 | 負電源（接地） |
|---|---|---|
| CMOS（MOSFET） | **V_DD**（D = Drain 汲極） | **V_SS**（S = Source 源極） |
| TTL（BJT） | **V_CC**（C = Collector 集極） | **GND** |

記法：DD 是電源（高）、SS 是地（低）。4000 系列 14 腳 IC：第 14 腳 V_DD、第 7 腳 V_SS。

### Q3. V_DD = 10 V、V_SS = 0 V、正邏輯的 CMOS IC，哪些敘述正確？（1-3.1）

| | 範圍 |
|---|---|
| 輸入邏輯 1 | **7 V 以上**（0.7 × 10） |
| 輸入邏輯 0 | **3 V 以下**（0.3 × 10） |
| 不允許 | 3 ～ 7 V |
| 輸出 1 | 約 10 V |
| 輸出 0 | 約 0 V |

- 「輸入 8 V 為 1」→ 對；「輸入 2 V 為 0」→ 對
- 「輸入 5 V 為 1」→ 錯，在不允許區
- 「2.0 V 以上為 1」→ 錯，那是 TTL

**為什麼？**
- 門檻用 V_DD 的比例表示：CMOS 的判斷點跟著電源走，廠商只保證 7 成以上一定是 1、3 成以下一定是 0，中間留給 IC 的誤差
- 輸出幾乎到電源和地：輸出端是一個 PMOS 接 V_DD、一個 NMOS 接地，一次只有一個導通，像開關直接接到電源或地；也因為電流不會直接從電源流到地，所以 CMOS 很省電

### Q4. 某邏輯族 V_OH = 4.4 V、V_OL = 0.1 V、V_IH = 3.15 V、V_IL = 1.35 V，低準位雜訊邊限 NM_L 為？（1-3.1）

**答：1.25 V**

```
NM_L = V_IL − V_OL = 1.35 − 0.1 = 1.25 V
NM_H = V_OH − V_IH = 4.4 − 3.15 = 1.25 V
```
記法：H 跟 H 相減、L 跟 L 相減，大減小。

### Q5. V_OH、V_IL、NM 這些英文是什麼？（1-3.1）

| 字母 | 英文 | 中文 |
|---|---|---|
| V | Voltage | 電壓 |
| I | Input | 輸入 |
| O | Output | 輸出 |
| H | High | 高準位（1） |
| L | Low | 低準位（0） |
| NM | Noise Margin | 雜訊邊限 |

| 符號 | 意思 |
|---|---|
| V_IH | 輸入至少這麼高才算 1 |
| V_IL | 輸入最多這麼低才算 0 |
| V_OH | 輸出 1 時至少這麼高 |
| V_OL | 輸出 0 時最多這麼低 |

### Q6. 雜訊邊限就是不允許區（或 0、1 範圍）的大小嗎？（1-3.1）

**答：不是**

```
 4.4 V  ── V_OH  ┐
                 │ NM_H = 1.25 V（輸出 1 的保證值 和 輸入 1 的門檻 之間）
 3.15 V ── V_IH  ┘ ┐
                   │ 不允許區 = 1.8 V（輸入的 0、1 門檻之間）
 1.35 V ── V_IL  ┐ ┘
                 │ NM_L = 1.25 V（輸入 0 的門檻 和 輸出 0 的保證值 之間）
 0.1 V  ── V_OL  ┘
```

| 名稱 | 算法 | 這題 |
|---|---|---|
| 不允許區 | V_IH − V_IL（只有 I） | 1.8 V |
| NM_H | V_OH − V_IH（O 和 I） | 1.25 V |
| NM_L | V_IL − V_OL（I 和 O） | 1.25 V |
| 輸入算 1 的範圍 | V_IH 以上 | 3.15 V 以上 |
| 輸入算 0 的範圍 | V_IL 以下 | 1.35 V 以下 |

- 雜訊邊限是一個**電壓大小**：訊號被雜訊干擾多少還不會判錯。越大越好
- 公式裡同時有 O 和 I → 雜訊邊限；只有 I → 不允許區

### Q7. 何種邏輯族屬於單極性邏輯？（1-4.4）

**答：MOS、CMOS（PMOS、NMOS、CMOS）**

| 單極性 | 雙極性 |
|---|---|
| PMOS、NMOS、CMOS | TTL、ECL、DTL、RTL |
| 元件：MOSFET | 元件：BJT |
| 只靠一種載子（電子或電洞） | 電子、電洞兩種載子都參與 |

- 📖 課本：CMOS 以單極性的 MOSFET 為主要元件
- CMOS 雖然 PMOS、NMOS 一起用，但每個 MOSFET 都只靠一種載子，所以仍是單極性

### Q8. PROM 是什麼？（1-4.1）

**答：可程式唯讀記憶體（Programmable Read-Only Memory），屬於 SPLD**

| | AND 陣列 | OR 陣列 |
|---|---|---|
| **PROM** | **固定** | **可程式** |
| PAL | 可程式 | 固定 |
| PLA | 可程式 | 可程式 |

- 固定的 AND 陣列其實是解碼器，會產生所有標準積項（m0、m1…），在 OR 陣列選要哪幾個，就能做出任何 Σm(…)
- 燒錄：PROM 用熔絲，只能燒一次；EPROM 用紫外線抹除；EEPROM 用電抹除

### Q9. 數位積體電路（1-4.1）

- IC 依電路屬性分：**類比 IC**（OPA、穩壓 IC）、**數位 IC**（邏輯閘、微處理器）、**混合訊號 IC**（ADC、DAC）
- 邏輯 IC 依使用方式分：**標準型邏輯 IC**（功能固定，如 7400）、**PLD**（自行規劃）
- PLD 依結構大小分：**SPLD**、**CPLD**、**FPGA**

### Q7.「用電晶體－電晶體邏輯元件製作的 IC 簡稱 CMOS IC」對嗎？（1-4.4）

**答：錯，應該是 TTL IC**

| 簡稱 | 全名 | 中文 |
|---|---|---|
| **TTL** | Transistor-Transistor Logic | 電晶體－電晶體邏輯 |
| **CMOS** | Complementary Metal-Oxide-Semiconductor | 互補式金屬氧化物半導體 |

### Q8.「標準 TTL IC 的工作電壓範圍比 CMOS IC 廣」對嗎？（1-4.4）

**答：錯，CMOS 比較廣**

| | 工作電壓 |
|---|---|
| 標準 TTL | **5 V ± 5%**（4.75 ～ 5.25 V） |
| CMOS（4000 系列） | **3 ～ 18 V** |

相關對錯：CMOS 功率比 TTL 小（對）；TTL 比傳統 CMOS 快（對）；CMOS 不怕靜電（錯）；74 和 54 系列差在電壓（錯，差在溫度）。

### Q10. 常用 14 支腳的雙排並列（DIP）IC 中，二輸入閘有幾個？（1-4.3、2-5）

**答：4 個**

14 支腳扣掉 V_CC、GND 剩 12 支；一個 2 輸入閘用 3 支腳（2 入 1 出）→ 12 ÷ 3 = 4

| 閘 | 每個用幾腳 | 個數 | 例子 |
|---|---|---|---|
| NOT | 2 | 6 | 7404 |
| 2 輸入 | 3 | 4 | 7400、7408、7432 |
| 3 輸入 | 4 | 3 | 7410 |
| 4 輸入 | 5 | 2 | 7420 |
| 8 輸入 | 9 | 1 | 7430 |

### Q11. 各個邏輯閘的圖示

見 [邏輯閘圖示（網站）](https://claude.ai/artifact/FDEn3DsT79YWNTvWLubCVn)，離線版：[邏輯閘圖示.html](邏輯閘圖示.html)

- 輸出有小圓圈 = 反相：NAND、NOR、XNOR、NOT
- IEEE 框內：& AND、≥1 OR、=1 XOR、= XNOR、1 NOT

### Q12. ⊕ 是什麼？（2-4.1）

**答：XOR（互斥或）的符號**

| 符號 | 運算 | 口訣 |
|---|---|---|
| A + B | OR | 有 1 就 1 |
| A · B | AND | 全 1 才 1 |
| A ⊕ B | XOR | 相異為 1 |
| A ⊙ B | XNOR | 相同為 1 |

- A ⊕ B = A′B + AB′
- A ⊕ B ⊕ C：1 的個數為奇數時 = 1

### Q13. 三輸入 XNOR 閘的輸出布林式？（2-4.2）

**答：Y = (A ⊕ B ⊕ C)′ = Σm(0, 3, 5, 6) = A′B′C′ + A′BC + AB′C + ABC′**

- 1 的個數為偶數（含 0 個）時輸出 1
- ⚠️ 兩個 2 輸入 XNOR 串接：(A ⊙ B) ⊙ C = A ⊕ B ⊕ C，結果變成奇數個 1 輸出 1，和三輸入 XNOR 閘不同

### Q14. 三輸入 NAND 的輸入為 A、E0、E1，要讓輸出 Y = A′，E0、E1 應接？（2-3.2）

**答：E0 = 1、E1 = 1**

- Y = (A · E0 · E1)′ = (A · 1 · 1)′ = A′
- 任一個是 0 → Y = (0)′ = 1，輸出固定為 1
- 類似：三輸入 NOR 要 Y = A′ → 控制端接 0；AND 要 Y = A → 接 1；OR 要 Y = A → 接 0

## Ch3 布林代數與第摩根定理

### Q15. 布林代數是誰發明的？（3-1.1）

**答：英國數學家布爾（George Boole），1854 年**

- 1938 年夏農（Shannon）把它應用到開關電路

### Q16. 化簡 X + X′ + Y（3-2）

**答：1**

X + X′ = 1（互補律）→ 1 + Y = 1

### Q17. B′ · B′ = ？（3-2）

**答：B′**（同一律 X · X = X）

| 式子 | 結果 |
|---|---|
| B′ · B′ | B′ |
| B′ + B′ | B′ |
| B′ · B | 0 |
| B′ + B | 1 |
| (B′)′ | B |

### Q18. 化簡 B′ + AB′ + A′B′（3-3）

**答：B′**

```
B′ + AB′ + A′B′ = B′(1 + A + A′) = B′ · 1 = B′
```
或用吸收律：其他項都含 B′，全部被單獨的 B′ 吸收。

### Q19. 化簡 (X + Y′)(X + Z′)(X + W′)（3-3）

**答：X + Y′Z′W′**

用分配律 (A + B)(A + C) = A + BC，共同的 X 拉出來，剩下的 AND 在一起。也可寫成 X + (Y + Z + W)′。

### Q20. 化簡 (A′ + B)B（3-3）

**答：B**

吸收律 X(X + Y) = X：(A′ + B) · B = B(B + A′) = B
或展開：A′B + BB = A′B + B = B

⚠️ 外面乘的若是括號裡變數的**補數**，要用消去律：(A′ + B) · A = AB

### Q21. 化簡 X + X′Y（3-3）

**答：X + Y**（消去律）

```
X + X′Y = (X + X′)(X + Y) = 1 · (X + Y) = X + Y
```

| 式子 | 第二項含 | 定理 | 結果 |
|---|---|---|---|
| X + XY | 原形 X | 吸收律 | X |
| X + X′Y | 補數 X′ | 消去律 | X + Y |
| X(X + Y) | 原形 X | 吸收律 | X |
| X(X′ + Y) | 補數 X′ | 消去律 | XY |

### Q22. 化簡 F = A + A′B + A′B′C（3-3）

**答：A + B + C**

```
F = A + A′B + A′B′C
  = A + B + A′B′C            消去律：A + A′B = A + B
  = (A + B) + (A + B)′C      第摩根：A′B′ = (A + B)′
  = A + B + C                消去律：X + X′C = X + C
```
規律：前面 OR 過的變數，後面出現它的補數都可以刪掉。

### Q23. (A + B)′ = A′ + B′ 對嗎？（3-4）

**答：錯，(A + B)′ = A′ · B′**

- 第摩根：斷線、變號，+ 一定要變成 ·
- A′ + B′ 其實是 (AB)′（NAND）

### Q24. 第摩根定理

```
(A + B)′ = A′ · B′        （NOR = 負 AND）
(A · B)′ = A′ + B′        （NAND = 負 OR）
```
- 口訣：斷線、變號，兩個動作一起做
- 兩層線：一次斷一層，從最外面開始
- AND 項變 OR 時要加括號：(AB + C)′ = (A′ + B′)C′
- 練習：(A + B + C)′ = A′B′C′；(A′B)′ = A + B′；(A + B′)′ = A′B；((AB)′ + C)′ = ABC′

### Q25. 化簡 ((AB)′(AB))′（3-4）

**答：1**

把 AB 看成 X：X′ · X = 0 → 0′ = 1

### Q26. 化簡 ((A + B)′(AB))′（3-4）

**答：1**

(A + B)′ · AB = A′B′ · AB = (AA′)(BB′) = 0 → 0′ = 1

### Q27. 化簡 (ABC)′ + A′B + C′（3-4）

**答：A′ + B′ + C′**（= (ABC)′）

```
(ABC)′ + A′B + C′
= A′ + B′ + C′ + A′B + C′     第摩根
= A′ + B′ + C′                A′ + A′B = A′（吸收）、C′ + C′ = C′
```

### Q28. 化簡 AB + (AB + A′B′)′，選項 (a) A′ + B′ (b) A′ + B (c) A + B (d) A + B′（3-4）

**答：(c) A + B**

```
AB + (AB + A′B′)′
= AB + (AB)′ · (A′B′)′              ① 第摩根，長線斷開，+ 變 ·
= AB + (A′ + B′)(A + B)             ② 兩塊再各自第摩根
= AB + A′A + A′B + B′A + B′B        ③ 展開
= AB +  0  + A′B + AB′ +  0         ④ A′A = 0、B′B = 0；B′A 寫成 AB′（交換律）
= AB + A′B + AB′                    ⑤ + 0 不變，刪掉
= A(B + B′) + A′B
= A + A′B
= A + B                             ⑥ 消去律
```

快速看法：AB + A′B′ 是 XNOR，反相變 XOR（A′B + AB′），再加 AB → 有 1 就 1 → A + B

⚠️ 讀題先看每條線從哪裡開始、到哪裡結束。長線蓋住整個 AB + A′B′；A、B 上面各自一條短線。

### Q29. 化簡 (A + (BC′)′ + CD)′ + ((BC)′)′（3-4）

**答：A′B + BC = B(A′ + C)**

```
第二塊：((BC)′)′ = BC

第一塊：(A + (BC′)′ + CD)′
      = A′ · BC′ · (C′ + D′)        第摩根、對合律
      = A′ · BC′                    BC′(C′ + D′) = BC′ + BC′D′ = BC′（吸收）

X = A′BC′ + BC
  = B(A′C′ + C)
  = B(A′ + C)                       消去律：C + C′A′ = C + A′
  = A′B + BC
```
D 被吸收掉，答案和 D 無關。

### Q30. 化簡 A′C + A′B + AB′C + BC（3-3）

**答：C + A′B**（標準積項和式 Σm(1, 2, 3, 5, 7)）

```
= C(A′ + AB′ + B) + A′B           有 C 的項提出來
A′ + AB′ = A′ + B′                消去律
A′ + B′ + B = 1                   B′ + B = 1
→ F = C + A′B
```

### Q31. 只用 2 輸入 NOR 閘組成 OR 閘，最少需要幾個？（3-5.2）

**答：2 個**

NOR₁：(A + B)′；NOR₂ 輸入接在一起當 NOT：((A + B)′)′ = A + B

| 要組成 | 用 NAND | 用 NOR |
|---|---|---|
| NOT | 1 | 1 |
| AND | 2 | 3 |
| OR | 3 | 2 |

### Q32. 等效符號（3-5.2）

**規則：形狀換（AND ↔ OR）、輸入和輸出的圓圈全部翻轉**

| 原本的閘 | 等效符號 | 公式 |
|---|---|---|
| NAND | 輸入有圈的 OR（負 OR） | (AB)′ = A′ + B′ |
| NOR | 輸入有圈的 AND（負 AND） | (A + B)′ = A′B′ |
| AND | 輸入、輸出都有圈的 OR | AB = (A′ + B′)′ |
| OR | 輸入、輸出都有圈的 AND | A + B = (A′B′)′ |

```
A ──┐                     A ──o┐
    │ AND )o── Y    ＝         ) OR ── Y        NAND ＝ 負 OR
B ──┘                     B ──o┘

A ──┐                     A ──o┐
    ) OR )o── Y     ＝          │ AND ── Y      NOR ＝ 負 AND
B ──┘                     B ──o┘
```
（o 代表小圓圈）

- ⚠️ 名字和等效形狀相反：NAND → OR 形狀；NOR → AND 形狀
- 用途：多層 NAND／NOR 電路把第二層換成等效符號，中間的圓圈兩兩抵消 → NAND-NAND = AB + CD、NOR-NOR = (A + B)(C + D)

### Q33. 只用 NOR 取代所有電路（3-5.2、3-5.4）

| 要做的閘 | 用幾個 NOR | 做法 |
|---|---|---|
| NOT | 1 | 輸入接在一起：(A + A)′ = A′ |
| OR | 2 | NOR + NOT |
| AND | 3 | A、B 先各自反相，再 NOR：(A′ + B′)′ = AB |
| NAND | 4 | AND + NOT |
| XNOR | 4 | 見下 |
| XOR | 5 | XNOR + NOT |

**4 個 NOR 做 XNOR**
- NOR₁：G₁ = (A + B)′ = A′B′
- NOR₂：(A + G₁)′ = (A + B′)′ = A′B
- NOR₃：(B + G₁)′ = (B + A′)′ = AB′
- NOR₄：(A′B + AB′)′ = A ⊙ B

**整個電路改成全 NOR**
- 和項積式（POS）→ OR-AND 兩層的閘直接全部換成 NOR：(A + B)(C + D) = ((A + B)′ + (C + D)′)′，共 3 個
- 單獨一個變數直接接第二層時要先反相：(A + B) · C = ((A + B)′ + C′)′
- 積項和式（SOP）→ 全 NAND；和項積式（POS）→ 全 NOR

### Q34. 只用 NAND 取代所有電路（3-5.2、3-5.4）

| 要做的閘 | 用幾個 NAND | 做法 |
|---|---|---|
| NOT | 1 | 輸入接在一起：(AA)′ = A′ |
| AND | 2 | NAND + NOT：((AB)′)′ = AB |
| OR | 3 | A、B 先各自反相，再 NAND：(A′B′)′ = A + B |
| NOR | 4 | OR + NOT |
| XOR | 4 | 見下 |
| XNOR | 5 | XOR + NOT |

**4 個 NAND 做 XOR**
- NAND₁：G₁ = (AB)′
- NAND₂：(A · G₁)′ = (A(A′ + B′))′ = (AB′)′
- NAND₃：(B · G₁)′ = (B(A′ + B′))′ = (A′B)′
- NAND₄：((AB′)′(A′B)′)′ = AB′ + A′B = A ⊕ B

**整個電路改成全 NAND**
- 積項和式（SOP）→ AND-OR 兩層的閘直接全部換成 NAND：AB + CD = ((AB)′(CD)′)′，共 3 個
- 原理：第二層的 NAND 等於負 OR，兩層之間的圓圈兩兩抵消
- 單獨一個變數直接接第二層時要先反相：AB + C = ((AB)′ · C′)′

**和 NOR 對照**

| 要組成 | NOT | AND | OR | NAND | NOR | XOR | XNOR |
|---|---|---|---|---|---|---|---|
| 用 NAND | 1 | **2** | 3 | — | 4 | **4** | 5 |
| 用 NOR | 1 | 3 | **2** | 4 | — | 5 | **4** |

記法：名字裡有的最快（NAND 做 AND、NOR 做 OR）；NAND 做 XOR、NOR 做 XNOR 各 4 個。

## Ch4 布林代數式（4-1、4-2）

### Q35. 標準積項和式是什麼？（4-1.2）

- **標準積項**：包含全部變數的積項，0 加 ′、1 原形（例：101 → AB′C = m5）
- **標準積項和式**：標準積項 OR 起來，寫成 **F = Σm(…)**
- 由真值表：看 **F = 1** 的列
- 由一般式：缺什麼變數就乘 (X + X′)；快速法是看每項在哪幾列等於 1
- 例：A′B + AC → A′B 是 2、3；AC 是 5、7 → Σm(2, 3, 5, 7)

### Q36. 和項積式是什麼？（4-1.2）

- **標準和項**：包含全部變數的和項，**0 原形、1 加 ′**（和標準積項相反；例：101 → A′ + B + C′ = M5）
- **標準和項積式**：標準和項 AND 起來，寫成 **F = ΠM(…)**
- 由真值表：看 **F = 0** 的列
- 由一般式：缺什麼變數就加 XX′，再用分配律拆開；快速法是看每個和項在哪幾列等於 0
- 例：(A + B)(A′ + C) → A + B 是 0、1；A′ + C 是 4、6 → ΠM(0, 1, 4, 6)
- 同一函數 Σm 和 ΠM 的編號互補：Σm(1, 3, 5, 6, 7) = ΠM(0, 2, 4)

### Q37. F(A, B, C) = ΠM(0, 1, 2)，則 F 的 Σm 形式為？（4-1.2）

**答：Σm(3, 4, 5, 6, 7)**

- ΠM 寫的是 F = 0 的列（0、1、2），Σm 寫的是 F = 1 的列 → 取剩下的 3～7
- 化簡：4～7 是 A = 1 → A；3 和 7 合併 → BC；所以 F = A + BC

| 已知 | 要求 | 規則 |
|---|---|---|
| F = ΠM(…) | F 的 Σm | 取剩下的編號 |
| F = Σm(…) | F′ 的 Σm | 取剩下的編號 |
| F = Σm(…) | F′ 的 ΠM | 編號不變 |

### Q38. Σ 是什麼？（4-1.2）

**答：sigma，全部 OR 起來**

- F = Σm(1, 3, 5) = m1 + m3 + m5 = A′B′C + A′BC + AB′C
- 意思：F 在 1、3、5 號是 1，其他是 0
- Π（pi）：全部 AND 起來，搭配 M（標準和項）

### Q39. F(A, B, C) 是什麼意思？（4-1.1）

**答：F 有 A、B、C 三個輸入，A 是最左邊的位元（權值 4、2、1）**

- 順序決定編號：F(A, B, C) 中 A = 1、B = 0、C = 0 是 4 號；F(C, B, A) 中同一組輸入是 1 號
- 變數數決定標準積項個數：2 變數 4 個、3 變數 8 個、4 變數 16 個

### Q40. 下列何者非標準積項和式？（4-1.2）

(A) f(A, B, C) = Σ(0, 1, 3, 7)
(B) f(A, B, C) = m0 + m1 + m3 + m4 + m6
(C) f(A, B, C) = A′B′C′ + A′BC′ + ABC′
(D) f(A, B, C) = A′BC + ABC′ + A′B′C′ + A′B′

**答：(D)**，最後一項 A′B′ 缺 C，不是標準積項。

- Σ(…) 和 m0 + m1 + … 本身就是標準積項和式
- 直接寫變數的，要一項一項檢查有沒有缺變數

### Q41. 輸入 A、B、C，三個相同時 F = 1，其他 F = 0（4-2.1）

**答：F = Σm(0, 7) = A′B′C′ + ABC**

- 三個相同只有 000、111 兩種
- 也可寫成 ΠM(1, 2, 3, 4, 5, 6)，但 Σm 比較好寫
