2-1 指數教學

這一節只要記住一句話：能化成同底，就化成同底。下面分成 7 步，每一步都會用到前一步，請照順序讀。
第 0 步

先看懂寫法

次方的數字寫在右上角，而且字比較小。

第 1 步

次方是什麼

次方就是「同一個數連乘好幾次」的簡寫。

an = a × a × … × a n 個 a 相乘

第 2 步

指數律：數一數有幾個

下面每一條規則都不用硬背，把次方展開數一數就知道了。

1 同底相乘，指數相加

23 × 22 = 2×2×2 × 2×2 = 25

3 個 2 再乘 2 個 2，總共 5 個 2。

am × an = am + n

2 同底相除，指數相減

25 ÷ 22 = 2 × 2 × 2 × 2 × 22 × 2 = 23

分子 5 個 2，分母 2 個 2，約掉 2 個，剩 3 個。

am ÷ an = am − n

3 次方的次方，指數相乘

(23)2 = 23 × 23 = 26

3 個一組，有 2 組，總共 3 × 2 = 6 個。

(am)n = am × n

4 乘在一起的次方，可以分給每一個

(a × b)n = an × bn　　(ab)n = anbn

例如 (2 × 3)2 = 22 × 32 = 4 × 9 = 36，跟 62 = 36 一樣。

指數律只能用在相乘、相除，不能用在相加：
  • 23 + 22 = 8 + 4 = 12，不是 25 = 32
  • (a + b)2 不等於 a2 + b2。例如 (1 + 2)2 = 9，但 12 + 22 = 5
檢查一下
  1. 24 × 23 = 2 的幾次方？
  2. 37 ÷ 35 = ？
  3. (52)3 = 5 的幾次方？
看答案
  1. 4 + 3 = 7，是 27
  2. 37 − 5 = 32 = 9
  3. 2 × 3 = 6，是 56
第 3 步

0 次方和負次方

「乘 0 次」「乘負 3 次」聽起來很奇怪，但只要看規律就懂了：指數每少 1，數值就除以底數一次。

底數
拖動指數，或點下面的格子。往左每走一格，數值就除以底數一次。
一定要背
a0 = 1 任何不是 0 的數，0 次方都是 1
a−n = 1an 負次方就是取倒數
例求 70、5−2、(23)−2。

5−2152 = 125
(2/3)−2分數的負次方，就是把分數倒過來再做次方：(32)2 = 94
2−1 = 12，不是 −2。次方的負號代表「倒數」，不會讓數字變成負的。
第 4 步

分數次方就是根號

右上角寫一個小分數，例如 912，意思就是開根號。

為什麼 912 = √9？

兩個 912 相乘，用第 2 步的「指數相加」：

912 × 912 = 9 的（12 + 12）次方 = 91 = 9

「自己乘自己等於 9」的數是 3，也就是 √9。所以 912 = √9 = 3。

一定要背
a1n = n√a 分母 n 是開幾次根號
amn = n√am = (n√a)m 分母當根號，分子當次方

第 6 步

三種必考題型

題型 A：乘法公式（平方技巧）

(x + 1x)2 = x2 + 2 + 1x2 中間的 2 是 2 × x × 1x = 2
例 4a12 + a−12 = 3，求 a + a−1。
兩邊平方(a12 + a−12)2 = 32 = 9
展開(a12)2 + 2 × a12 × a−12 + (a−12)2 = a + 2 + a−1
為什麼是 2a12 × a−12 = a0 = 1，正負次方相乘剛好抵消
答案a + 2 + a−1 = 9，所以 a + a−1 = 7

再平方一次：(a + a−1)2 = a2 + 2 + a−2 = 49，所以 a2 + a−2 = 47。

題型 B：解指數方程式

方法一：化成同底，指數就相等。如果 2□ = 2○，那麼 □ = ○。

例 5解 2x+1 = 18。
化同底18 = 2−3，所以 2x+1 = 2−3
指數相等x + 1 = −3，x = −4
例 6解 9x = 27。
化同底9x = (32)x = 32x，27 = 33
指數相等2x = 3，x = 32

方法二：提出公因式。

例 7解 3x+1 + 3x = 36。
拆開3x+1 = 3x × 31 = 3 × 3x
提出3 × 3x + 3x = (3 + 1) × 3x = 4 × 3x = 36
答案3x = 9 = 32，x = 2

方法三：令 t，變成一元二次方程式。看到 4x 和 2x 一起出現，就令 t = 2x。因為 4x = (22)x = (2x)2，所以 4x = t2。

例 8解 4x − 6 × 2x + 8 = 0。
令 tt = 2x，方程式變成 t2 − 6t + 8 = 0
因式分解(t − 2)(t − 4) = 0，t = 2 或 t = 4
換回來2x = 2 = 21，x = 1；2x = 4 = 22，x = 2
答案x = 1 或 x = 2
t = 2x 一定大於 0。如果解出來 t 是負數，那個答案要捨去。例如 t2 − 2t − 8 = 0 解出 t = 4 或 t = −2，t = −2 要丟掉，只留 t = 4。
