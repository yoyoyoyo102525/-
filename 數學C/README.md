## 模擬考功能

- 題庫 124 題：先備 4、1-1 33、1-2 35、2-1 23、2-2 29
- 每按一次「出一份新考卷」就隨機抽題、打亂選項，每份考卷都不一樣
- 範圍可選全部、先備、1-1、1-2、2-1、2-2、錯題本；題數可選 25 題、10 題或該範圍全部
- 交卷後自動改分（換算成 100 分）並附解析，答錯和沒作答的題目會收進錯題本，在錯題本答對就會移出
