和差角公式

特殊角只有 30°、45°、60° 這幾個。這節教你把兩個角加起來或減掉，算出 75°、15° 這類角的值。再延伸出二倍角、半角和疊合。

1和差角公式

一定要背
sin(α + β) = sin α cos β + cos α sin β
sin(α − β) = sin α cos β − cos α sin β
cos(α + β) = cos α cos β − sin α sin β
cos(α − β) = cos α cos β + sin α sin β
tan(α + β) = tan α + tan β1 − tan α tan β
tan(α − β) = tan α − tan β1 + tan α tan β
sin 公式是「sin cos、cos sin，符號照抄」（左邊 +，右邊也是 +）。cos 公式是「cos cos、sin sin，符號相反」（左邊 +，右邊變 −）。tan 公式的分子符號照抄，分母符號相反。
sin(α + β) ≠ sin α + sin β。三角函數不能直接拆開。

複數平面

把複數 a + bi 畫成平面上的一個點，再用「長度」和「角度」來表示它，這種寫法叫極式。用極式做乘法、除法和次方會非常快。

1虛數 i 和它的次方

i² = −1
i¹ = i，i² = −1，i³ = −i，i⁴ = 1，然後每 4 個重複一次
求 i2026。
2026 ÷ 4 = 506 餘 2，所以 i2026 = i² = −1
次方除以 4 看餘數：餘 1 是 i，餘 2 是 −1，餘 3 是 −i，整除是 1。另外，連續 4 個次方加起來一定是 0：i + i² + i³ + i⁴ = 0。

2複數的四則運算

複數 z = a + bi，a 叫實部，b 叫虛部（虛部是 b，不含 i）。兩個複數相等，代表實部相等而且虛部也相等。

加減：實部和實部算，虛部和虛部算
乘法：像多項式一樣展開，遇到 i² 就換成 −1
除法：分子分母同乘「分母的共軛複數」
求 (2 + 3i)(1 − i)。
= 2 − 2i + 3i − 3i² = 2 + i + 3 = 5 + i
求 3 + 4i1 + 2i。
同乘共軛(3 + 4i)(1 − 2i)(1 + 2i)(1 − 2i)
分母1² + 2² = 5（(a + bi)(a − bi) = a² + b²）
分子3 − 6i + 4i − 8i² = 3 − 2i + 8 = 11 − 2i
答案115 − 25i

3複數平面、共軛、絕對值

z = a + bi 對應平面上的點 (a, b) 橫軸是實軸，縱軸是虛軸
共軛複數 z̄ = a − bi 對實軸（x 軸）對稱
|z| = √a² + b² 點到原點的距離
|z₁ − z₂| = 兩點之間的距離
絕對值的性質
|z₁ z₂| = |z₁||z₂|　　|z₁z₂| = |z₁||z₂|　　|zⁿ| = |z|ⁿ
|z̄| = |z|　　z · z̄ = |z|² = a² + b²
求 |3 + 4i|，以及 1 + 2i 和 4 + 6i 兩點的距離。
|3 + 4i| = √9 + 16 = 5。距離 = |(4 + 6i) − (1 + 2i)| = |3 + 4i| = 5
求 |(3 + 4i)(1 − i)| 和 |(1 + i)10|。
不用展開，直接用性質。|3 + 4i|·|1 − i| = 5·√2 = 5√2。|1 + i|10 = (√2)10 = 2⁵ = 32
z = 3 − 2i，求 z̄ 和 z · z̄。
z̄ = 3 + 2i，z · z̄ = 3² + 2² = 13
|z| = 2 代表所有到原點距離是 2 的點，也就是圓心在原點、半徑 2 的圓。|z − (1 + i)| = 3 是圓心 (1, 1)、半徑 3 的圓。

4極式（本節最重要）

一定要背
z = r(cos θ + i sin θ)
r = |z| = √a² + b²（長度，一定是正的）　θ = 從正實軸逆時針轉到 z 的角度（輻角）

化成極式的四個步驟

  1. 算 r = √a² + b²
  2. 把 r 提出來：z = r(ar + br i)
  3. 找一個角 θ，讓 cos θ = ar、sin θ = br
  4. 看點 (a, b) 在第幾象限，確認 θ 沒有算錯
把 −1 + √3 i 化成極式。
步驟 1r = √1 + 3 = 2
步驟 2z = 2(−12 + √32 i)
步驟 3cos θ = −12、sin θ = √32，點 (−1, √3) 在第二象限，θ = 120°

乘上 (cos θ + i sin θ)，就是把點繞原點逆時針轉 θ 度。乘上 i 等於轉 90°，因為 i = cos 90° + i sin 90°。
點 z = 3 + i 繞原點逆時針旋轉 90°，會到哪裡？
乘上 i：i(3 + i) = 3i + i² = −1 + 3i，也就是點 (−1, 3)

指數

把「次方」從正整數擴充到 0、負數和分數，並學會用指數律化簡式子、解指數方程式。核心技巧只有一個：化成同底。

1指數的定義

一定要背（a > 0）
aⁿ = a × a × … × a（n 個 a 相乘）
a⁰ = 1 任何非 0 的數的 0 次方都是 1
a−n = 1aⁿ 負次方就是取倒數
a1/n = n√a　　am/n = n√aᵐ = (n√a)ᵐ 分母當根號，分子當次方
求 5⁰、2⁻³、(23)⁻²、91/2、81/3。
5⁰ = 1；2⁻³ = 18；(23)⁻² = (32)² = 94；91/2 = √9 = 3；81/3 = 3√8 = 2

2指數律

一定要背
aᵐ · aⁿ = am+n 同底相乘，次方相加
aᵐ ÷ aⁿ = am−n 同底相除，次方相減
(aᵐ)ⁿ = amn 次方的次方，次方相乘
(ab)ⁿ = aⁿbⁿ　　(ab)ⁿ = aⁿbⁿ
  • (a + b)ⁿ ≠ aⁿ + bⁿ，例如 (1 + 2)² = 9，但 1² + 2² = 5
  • aᵐ + aⁿ ≠ am+n，「次方相加」只適用於相乘
  • −2² = −4，(−2)² = 4，括號差很多
  • 2⁻¹ = 12，不是 −2

5指數方程式

方法一：化成同底，次方就相等。如果 ax = ay，那 x = y。

解 2x+1 = 18 和 9x = 27。
第一題2x+1 = 2⁻³，所以 x + 1 = −3，x = −4
第二題32x = 3³，所以 2x = 3，x = 32

方法二：提出公因式。

解 3x+1 + 3x = 36。
3x+1 = 3 · 3x，所以 3x(3 + 1) = 36，3x = 9 = 3²，x = 2

方法三：令 t 換成一元二次方程式。看到 4x 和 2x 一起出現，就令 t = 2x，那麼 4x = t²。

解 4x − 6 · 2x + 8 = 0。
令 tt = 2x（t > 0），方程式變成 t² − 6t + 8 = 0
因式分解(t − 2)(t − 4) = 0，t = 2 或 t = 4
換回來2x = 2 得 x = 1；2x = 4 得 x = 2
答案x = 1 或 x = 2
令 t = 2x 時，t 一定大於 0。如果解出 t 是負數或 0，那個解要捨去。
換你試試
  1. 32−3/5 = ？
  2. 2x + 2−x = 3，求 4x + 4−x。
  3. 解 4x = 8x−1。
  4. 解 9x − 2 · 3x − 3 = 0。
看答案
  1. (2⁵)−3/5 = 2⁻³ = 18
  2. 平方：4x + 2 + 4−x = 9，所以答案是 7
  3. 22x = 23x−3，所以 2x = 3x − 3，x = 3

指數函數及其圖形

y = ax 的圖形長什麼樣子，以及怎麼用圖形比大小、解不等式。最後是統測很愛考的應用題：細菌繁殖、半衰期、複利。

1指數函數的圖形

指數函數 y = ax，規定 a > 0 而且 a ≠ 1。（a = 1 時 y 永遠是 1，只是一條水平線。）

性質a > 1（例如 2x）0 < a < 1（例如 (1/2)x）
一定通過的點(0, 1)，因為 a⁰ = 1
x 的範圍（定義域）所有實數
y 的範圍（值域）y > 0 （圖形永遠在 x 軸上方）
遞增或遞減遞增（往右越來越高）遞減（往右越來越低）
漸近線x 軸（y = 0）：越來越靠近，但永遠碰不到
y = ax 和 y = (1a)x 的圖形對稱於 y 軸，例如 2x 和 (1/2)x。在 x > 0 的部分，底數越大，圖形越陡（3x 在 2x 上面）。

2平移和對稱

y = ax−h + k：把 y = ax 往右移 h、往上移 k 漸近線變成 y = k
y = a−x：對 y 軸對稱　　y = −ax：對 x 軸對稱
x − 1 是往右移 1，不是往左。括號裡的減號代表往右，加號代表往左。
y = 2x−1 + 3 的漸近線是什麼？圖形一定通過哪一點？
從 y = 2x 往右移 1、往上移 3。漸近線從 y = 0 上移成 y = 3；原本的 (0, 1) 移到 (1, 4)

3比大小

一定要背
底數 a > 1：次方越大，值越大 遞增
底數 0 < a < 1：次方越大，值越小 遞減，方向相反
比較 a = 20.6、b = 40.25、c = (12)−0.7 的大小。
化同底b = (2²)0.25 = 20.5；c = (2⁻¹)−0.7 = 20.7
比次方底數 2 > 1，次方 0.5 < 0.6 < 0.7
答案b < a < c
比較 (13)0.2 和 (13)0.5。
底數 13 < 1，方向相反：0.2 < 0.5，所以 (13)0.2 > (13)0.5
比較 3√3 和 √2。
兩個底數不同，改成同樣的「6 次方根」：3√3 = 31/3 = 32/6 = 6√9；√2 = 23/6 = 6√8。9 > 8，所以 3√3 > √2

4指數不等式

跟解方程式一樣先化成同底。接著看底數：底數大於 1，不等號方向不變；底數小於 1，不等號要反過來。

解 2x > 8 和 (13)x > 9。
第一題2x > 2³，底數 2 > 1，方向不變：x > 3
第二題(13)x > (13)⁻²，底數 < 1，方向反過來：x < −2
解 (12)x−1 ≤ 4。
4 = (12)⁻²，所以 (12)x−1 ≤ (12)⁻²。底數 < 1，方向反過來：x − 1 ≥ −2，x ≥ −1
解 4x − 3 · 2x − 4 < 0。
令 tt = 2x > 0：t² − 3t − 4 < 0
分解(t − 4)(t + 1) < 0，−1 < t < 4。再加上 t > 0，得 0 < t < 4
換回來2x < 4 = 2²，所以 x < 2

5應用題（統測素養題常考）

倍增：數量 = 原本 × 2經過時間 ÷ 倍增時間
半衰期：剩下 = 原本 × (12)經過時間 ÷ 半衰期
複利：本利和 = 本金 × (1 + 利率)期數
細菌每小時數量變成 2 倍，一開始有 100 隻，5 小時後有幾隻？
100 × 2⁵ = 100 × 32 = 3200 隻
某放射性物質半衰期是 5 年，現在有 100 克，15 年後剩多少？
15 ÷ 5 = 3 個半衰期，100 × (12)³ = 12.5 克
本金 10000 元，年利率 10%，每年複利一次，2 年後本利和是多少？
10000 × (1.1)² = 10000 × 1.21 = 12100 元
交點個數題：問「2x = −x + 3 有幾個實數解」，就是問兩個圖形有幾個交點。y = 2x 一路往上，y = −x + 3 一路往下，所以只會交一次，答案是 1 個解。
換你試試
  1. 比較 0.5−1.2、0.50.3、1 的大小。
  2. 解 32x−1 < 27。
  3. y = 3x+2 − 1 的漸近線？圖形會不會通過第幾象限？（提示：它會不會跑到 y < −1？）
  4. 某藥物在體內每小時剩下原本的一半，注射 80 毫克，4 小時後剩多少？
看答案
  1. 1 = 0.5⁰。底數 0.5 < 1，次方越大值越小：−1.2 < 0 < 0.3，所以 0.5−1.2 > 1 > 0.50.3
  2. 32x−1 < 3³，2x − 1 < 3，x < 2
  3. 漸近線 y = −1。y 永遠大於 −1，圖形會經過第一、二、三象限，但不經過第四象限（x > 0 時 y > 3² − 1 = 8，都在 x 軸上方）
  4. 80 × (12)⁴ = 5 毫克
