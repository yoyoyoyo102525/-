## 測驗功能

- 範圍：全部、Ch1、Ch2、Ch3、小考、測驗卷＋統測、錯題本
- 勾「隨機」會同時打亂題目順序和選項順序
- 鍵盤：`1`–`4` 作答，`Enter` 下一題
- 錯題本存在瀏覽器裡，換電腦或清除瀏覽資料就會不見
