課本沒有、小考有考的內容 ⭐

發展史

  • 點接觸電晶體（1947，材料是鍺）：巴丁、卜拉登、蕭特力
  • 基爾比：用鍺做出第一個 IC（1958）

真空管與 IC 製程

  • 真空管缺點：體積大、容易發熱、壽命短（「有開關特性」不是缺點）
  • IC 製程：晶圓切片最先 → 光罩、蝕刻 → 晶粒切割 → 打線 → 測試（販售不是製程）

波形

  • 正弦波是基本組成波：不同頻率的正弦波可以組成任意波形
  • 方波 C.F. = F.F. = 1；F.F. 最小的是方波
  • AC 110 V 指的是有效值 110 V
  • 直流成分是負的也照樣平方：−2 + 2√2 sin ωt → Vrms = 2√2 V

二極體、稽納

  • 熱電壓 V_T = kT/q，27 °C（300 K）時 ≈ 26 mV
  • 崩潰電壓的溫度變化：稽納崩潰 → 溫度↑電壓↓；累增崩潰 → 溫度↑電壓↑
  • 稽納動態電阻：r_z = (V_Z − V_ZK) / (I_Z − I_ZK)
  • 兩顆稽納背對背串接：一顆順偏（理想 0 V）、一顆崩潰（V_Z）
  • 理想稽納：順偏 0 V、逆向崩潰 V_Z
  • 多顆二極體接到不同負電壓：接到越負的那顆先導通，用重疊定理算 Vo，再檢查其他顆是否逆偏

LED、OLED

  • 遙控器用紅外線 LED
  • LED 的光是散射光（不是聚合光）；發光原理不同於日光燈
  • 能隙愈大 → 波長愈短；波長愈長 → 頻率愈低
  • OLED 優點：輕薄、色彩鮮豔、高對比、可彎曲；缺點：壽命短、會烙印

BJT

  • 判斷逆向主動：I_C = I_B + I_E（電流關係反過來）
  • E 極既可當輸入（CB）也可當輸出（CC）
  • 座標法判斷工作區（橫軸 V_BE、縱軸 V_BC）：
    象限NPNPNP
    第一（V_BE > 0、V_BC > 0）飽和截止
    第二（V_BE < 0、V_BC > 0）逆向主動順向主動
    第三（V_BE < 0、V_BC < 0）截止飽和
    第四（V_BE > 0、V_BC < 0）順向主動逆向主動
  • PNP 的 CE 輸出特性曲線畫在第二象限（V_CE < 0）
  • 輸出曲線在主動區幾乎水平：V_CE 對 I_C 影響很小

真空管 vs 半導體 ⭐

  • 真空管：陰極要先加熱才能發射電子 → 材料易變質、易故障；玻璃管又大又重又易碎。優點：音頻響應好、適合大功率 → 少數音響設備還在用。
  • 半導體：體積小、省電、成本低、不易損壞、中頻響應好 → 逐漸取代真空管。

1-2 基本波形 ⭐

波形振幅極性
純直流不變不變
脈動直流會變不變
交流會變會變
  • 交流分週期性（會重複）與非週期性（不規則，如雜訊）。
  • 純交流：一個週期的平均值 = 0，沒有直流成份。
  • 交直流混波 = 直流成份 + 交流成份（如 v(t) = 5 + 5 sin ωt）。
    • 判斷技巧：最低點 < 0 → 極性有變 → 屬於「交流電」；最低點 ≥ 0 → 脈動直流。
  • 基本交流波形：正弦波、方波、三角波

基本數值定義

  • Vm：最大值（峰值）
  • T：週期 (s)，f：頻率 (Hz)，f = 1/T
  • Vp-p = 2Vm（峰對峰值）
  • Veff = Vrms：有效值＝在電阻上產生相同平均功率的等效直流值
  • Vdc = Vav：直流值（平均值）
  • 音頻範圍：20 Hz ~ 20 kHz

正弦波 ⭐⭐

  • 瞬時式：v(t) = Vm sin(ωt + θ)，ω = 2πf = 2π/T
  • 超前波 +θ，落後波 −θ
  • 常見 ω ↔ f：377 → 60 Hz、314 → 50 Hz、785 → 125 Hz、1000 → 159 Hz
  • 計算瞬時值的步驟：先算 ωt 換成角度 → 加相位 → 查特殊角
    • 特殊角：sin30° = 1/2、sin45° = √2/2、sin60° = √3/2、sin150° = 1/2、sin240° = −√3/2、sin270° = −1
    • 小技巧：t 是 T 的幾分之幾，角度就是 360° 的幾分之幾（t = ¾T → 270°）

方波與脈波 ⭐

  • 方波：工作週期 50%（T₁ = T₂）
  • 前緣（正緣）：Lo → Hi；後緣（負緣）：Hi → Lo
  • 窄脈波：T₁ < T₂（高準位時間較短）；寬脈波：T₁ > T₂
  • PW（脈波寬度）＝高準位時間；SW（空間寬度）＝低準位時間
  • T = PW + SW，工作週期 D = PW / T × 100%
  • 若低準位 = 0：Vav = Vm × D

三角波與鋸齒波

  • 三角波：正、負斜率大小相等
  • 鋸齒波：正、負斜率大小不相等（分正向 / 負向鋸齒波）
  • 斜率 m = ΔV / Δt（單位常用 V/ms）

  • 正弦波：Vav = 0.9 Vrms、Vrms = 1.11 Vav

比大小（常考陷阱） ⭐

  • 相同峰值 → 有效值（功率）：方 > 正 > 三
  • 相同有效值 → 功率一樣大
  • 相同平均值 → 有效值（功率）：三 > 正 > 方（因為 F.F. 三角波最大）

分段週期波形的 Vrms（每一段先求自己的有效值再平方乘時間）：

Vrms = √[ (Vrms1² × Δt1 + Vrms2² × Δt2 + …) / T ]
Vav  = (波形面積和) / T      ← 面積有正有負要相減

交直流混波：Vrms = √( Vdc² + Vac(rms)² )，平均值 = 直流項

  • 例：v = 4 + 3√2 sin ωt → Vrms = √(4² + 3²) = 5 V，Vav = 4 V

兩個同頻率正弦相加（Vm 相同時）：相位差 60° → ×√3；90° → ×√2；120° → ×1；新相角取平均。

    • 摻雜後仍是電中性（雜質原子本身是電中性的）⭐

2-6 稽納穩壓電路 ⭐⭐

  • 在濾波電路輸出端並接稽納二極體（串 R_S 限流），得到更穩的直流
  • 用重疊定理分成直流與交流分析，最後 V_L(總) = V_L(直流) + v_L(交流)

直流分析（稽納看成 V_Z 電池）

  • DC × R_L/(R_S + R_L) ≥ V_Z → 稽納崩潰，V_L = V_Z
  • 否則稽納開路，V_L = DC × R_L/(R_S + R_L)
  • 若有內阻 r_Z：稽納 = V_Z 電池串 r_Z，用節點電壓法解

交流分析（稽納看成電阻 r_Z = ΔV_Z / ΔI_Z）

v_L = AC × (R_L // r_Z) / [ r_S + (R_L // r_Z) ]

範例 2-12 類型：E = 15 V、R = R_L = 30 Ω、V_Z = 5 V、r_Z = 10 Ω

  • 節點：(V − 15)/30 + (V − 5)/10 + V/30 = 0 → V_L = 6 V
  • I_Z = (6 − 5)/10 = 0.1 A；P_Z = V_Z I_Z + I_Z² r_Z = 0.5 + 0.1 = 0.6 W
  • ΔE = 10 mV → ΔV_L = 10m × (30//10)/(30 + 30//10) = 10m × 7.5/37.5 = 2 mV

電壓調整率 VR% ⭐⭐

VR% = (V_NL − V_FL) / V_FL × 100%
  • V_NL 無載電壓（拿掉負載，R_L = ∞）；V_FL 滿載電壓（接上負載）
  • 越小越好，理想 VR% = 0
  • 也等於「電源內阻電壓 ÷ 負載電壓」
  • 理想電壓源內阻 = 0；理想電流源內阻 = ∞

為什麼稽納多拿來當參考電壓，而不是穩壓元件？ 可選的電壓值有限、最大電流太小容易燒毀（I_Z 太大 → P_Z 太大）、是被動元件，會受負載影響。

Ch3 雙極性接面電晶體 (BJT)

3-1 構造 ⭐

  • BJT（bipolar junction transistor），主動元件，可做放大與開關；1947 年貝爾實驗室。
  • 分 NPN 與 PNP，三極：射極 E、基極 B、集極 C
  • 兩個接面：J_E（B-E 接面）、J_C（B-C 接面）
  • 功能：E 發射多數載子、B 控制載子數量、C 收集載子
  • ⭐ 摻雜濃度：E > B > C
  • ⭐ 寬度（體積）：C > E > B（B 約為整體的 1/150；C 最大，與外殼相接散熱用）
  • 符號箭頭＝電流方向（P 指向 N）：NPN 箭頭朝外（B→E），PNP 箭頭朝內（E→B）
  • 多數載子：NPN = 電子、PNP = 電洞
  • 電流同時含電子流與電洞流 → 又稱雙載子元件

  • 電晶體當開關 ON → 飽和區；截止區、飽和區合起來可視為開關元件
  • 溫度上升 → 工作點往飽和區偏移（β、I_CBO 都會變大）
  • 三個參數中 β 最容易受溫度影響
  • 固定偏壓的穩定性最差
  • 集極回授偏壓絕對不會進入飽和區
  • 想得到最大不失真輸出 → Q 點放在負載線中點
  • 提高 V_CC，負載線斜率不變（斜率 = −1/R_C，只是平移）
