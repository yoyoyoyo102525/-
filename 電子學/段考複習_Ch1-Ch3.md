### 課本沒有、小考有考的內容 ⭐

**發展史**
- 點接觸電晶體（1947，材料是**鍺**）：**巴丁、卜拉登、蕭特力**
- **基爾比**：用鍺做出**第一個 IC**（1958）

**真空管與 IC 製程**
- 真空管缺點：體積大、容易發熱、壽命短（「有開關特性」不是缺點）
- IC 製程：**晶圓切片最先** → 光罩、蝕刻 → 晶粒切割 → 打線 → 測試（販售不是製程）

**波形**
- 正弦波是**基本組成波**：不同頻率的正弦波可以組成任意波形
- 方波 C.F. = F.F. = 1；F.F. 最小的是方波
- AC 110 V 指的是**有效值** 110 V
- 直流成分是負的也照樣平方：−2 + 2√2 sin ωt → Vrms = 2√2 V

**二極體、稽納**
- 熱電壓 **V_T = kT/q**，27 °C（300 K）時 ≈ **26 mV**
- 崩潰電壓的溫度變化：**稽納崩潰 → 溫度↑電壓↓**；**累增崩潰 → 溫度↑電壓↑**
- 稽納動態電阻：**r_z = (V_Z − V_ZK) / (I_Z − I_ZK)**
- 兩顆稽納背對背串接：一顆順偏（理想 0 V）、一顆崩潰（V_Z）
- 理想稽納：順偏 0 V、逆向崩潰 V_Z
- 多顆二極體接到不同負電壓：**接到越負的那顆先導通**，用重疊定理算 Vo，再檢查其他顆是否逆偏

**LED、OLED**
- 遙控器用**紅外線 LED**
- LED 的光是**散射光**（不是聚合光）；發光原理**不同於日光燈**
- **能隙愈大 → 波長愈短**；波長愈長 → 頻率愈低
- OLED 優點：輕薄、色彩鮮豔、高對比、可彎曲；**缺點：壽命短、會烙印**

**BJT**
- 判斷逆向主動：**I_C = I_B + I_E**（電流關係反過來）
- **E 極**既可當輸入（CB）也可當輸出（CC）
- 座標法判斷工作區（橫軸 V_BE、縱軸 V_BC）：

  | 象限 | NPN | PNP |
  |---|---|---|
  | 第一（V_BE > 0、V_BC > 0） | 飽和 | 截止 |
  | 第二（V_BE < 0、V_BC > 0） | 逆向主動 | 順向主動 |
  | 第三（V_BE < 0、V_BC < 0） | 截止 | 飽和 |
  | 第四（V_BE > 0、V_BC < 0） | 順向主動 | 逆向主動 |

- PNP 的 CE 輸出特性曲線畫在**第二象限**（V_CE < 0）
- 輸出曲線在主動區幾乎水平：**V_CE 對 I_C 影響很小**

### 真空管 vs 半導體 ⭐
- **真空管**：陰極要先**加熱**才能發射電子 → 材料易變質、易故障；玻璃管又大又重又易碎。**優點：音頻響應好、適合大功率** → 少數**音響設備**還在用。
- **半導體**：體積小、省電、成本低、不易損壞、中頻響應好 → 逐漸取代真空管。

### 積體電路分類 ⭐⭐（必考）

| 種類 | 零件（元件）數 | 邏輯閘數 | 老師補充：例子 |
|---|---|---|---|
| SSI 小型 | < 100 | < 12 | 基本閘 (74xx)、正反器 |
| MSI 中型 | 100 ~ 1k | 12 ~ 100 | 解碼器、多工器、ROM |
| LSI 大型 | 1k ~ 10k | 100 ~ 1000 | 單晶片微處理器、RAM |
| VLSI 超大型 | 10k ~ 100k | 1000 ~ 10000 | Intel CPU、手機 CPU、DRAM |
| ULSI 極大型 | > 100k | > 10000 | |

- 大小排序：**ULSI > VLSI > LSI > MSI > SSI**
- 記法：零件數 **10² → 10³ → 10⁴ → 10⁵**；邏輯閘 **12 → 10² → 10³ → 10⁴**
- 依電路屬性分：數位 IC（邏輯閘、正反器、微處理器）、類比 IC（感測器、類比運算）、混合訊號 IC（**A/D、D/A 轉換器**）
- 名詞：台灣叫「積體電路」，中國叫「集成電路」

### 4C 與 3C ⭐
- **4C（電子學技術）**：元件 components、通訊 communication、計算 computation、控制 control
  - 元件 → 微小化、通訊 → 遠距化、計算 → 準確化、控制 → 精密化
- **3C**：電腦、通訊、消費性電子（不要跟 4C 搞混！）

### 1-2 基本波形 ⭐

| 波形 | 振幅 | 極性 |
|---|---|---|
| 純直流 | 不變 | 不變 |
| 脈動直流 | **會變** | 不變 |
| 交流 | 會變 | **會變** |

- 交流分**週期性**（會重複）與**非週期性**（不規則，如雜訊）。
- **純交流**：一個週期的**平均值 = 0**，沒有直流成份。
- **交直流混波** = 直流成份 + 交流成份（如 v(t) = 5 + 5 sin ωt）。
  - 判斷技巧：**最低點 < 0 → 極性有變 → 屬於「交流電」**；最低點 ≥ 0 → 脈動直流。
- 基本交流波形：**正弦波、方波、三角波**

### 基本數值定義
- Vm：最大值（峰值）
- T：週期 (s)，f：頻率 (Hz)，**f = 1/T**
- **Vp-p = 2Vm**（峰對峰值）
- Veff = Vrms：**有效值**＝在電阻上產生相同平均功率的等效直流值
- Vdc = Vav：**直流值（平均值）**
- 音頻範圍：**20 Hz ~ 20 kHz**

### 正弦波 ⭐⭐
- 瞬時式：**v(t) = Vm sin(ωt + θ)**，**ω = 2πf = 2π/T**
- 超前波 +θ，落後波 −θ
- 常見 ω ↔ f：**377 → 60 Hz**、**314 → 50 Hz**、785 → 125 Hz、1000 → 159 Hz
- 計算瞬時值的步驟：先算 ωt 換成角度 → 加相位 → 查特殊角
  - 特殊角：sin30° = 1/2、sin45° = √2/2、sin60° = √3/2、sin150° = 1/2、sin240° = −√3/2、sin270° = −1
  - 小技巧：t 是 T 的幾分之幾，角度就是 360° 的幾分之幾（t = ¾T → 270°）

### 方波與脈波 ⭐
- 方波：工作週期 **50%**（T₁ = T₂）
- **前緣（正緣）**：Lo → Hi；**後緣（負緣）**：Hi → Lo
- **窄脈波**：T₁ < T₂（高準位時間較短）；**寬脈波**：T₁ > T₂
- PW（脈波寬度）＝高準位時間；SW（空間寬度）＝低準位時間
- **T = PW + SW**，**工作週期 D = PW / T × 100%**
- 若低準位 = 0：**Vav = Vm × D**

### 三角波與鋸齒波
- 三角波：正、負斜率**大小相等**
- 鋸齒波：正、負斜率**大小不相等**（分正向 / 負向鋸齒波）
- 斜率 m = ΔV / Δt（單位常用 V/ms）

### 有效值與平均值 ⭐⭐⭐（計算題主力）

| 波形 | 最大值 | 有效值 Vrms | 正半週平均 Vav | 波峰因數 C.F. = Vm/Vrms | 波形因數 F.F. = Vrms/Vav |
|---|---|---|---|---|---|
| 正弦波 | Vm | Vm/√2 = **0.707Vm** | 2Vm/π = **0.636Vm** | √2 = **1.414** | ≈ **1.11** |
| 方波 | Vm | **Vm** | **Vm** | **1** | **1** |
| 三角波 | Vm | Vm/√3 = **0.577Vm** | Vm/2 = **0.5Vm** | √3 = **1.732** | ≈ **1.154** |
| 純直流 | Vm | Vm | Vm | 1 | 1 |

- **C.F. 波峰因數**：判別電源電路系統優劣；**F.F. 波形因數**：儀器數值換算
- 正弦波：Vav = 0.9 Vrms、Vrms = 1.11 Vav
- **半波**（只有半個週期有正弦）：Vrms = Vm/2，Vav = Vm/π = 0.318Vm
- **全波**（每半週都是正的）：Vrms = Vm/√2，Vav = 2Vm/π

**比大小（常考陷阱）** ⭐
- **相同峰值** → 有效值（功率）：**方 > 正 > 三**
- **相同有效值** → 功率**一樣大**
- **相同平均值** → 有效值（功率）：**三 > 正 > 方**（因為 F.F. 三角波最大）

**分段週期波形的 Vrms**（每一段先求自己的有效值再平方乘時間）：

```
Vrms = √[ (Vrms1² × Δt1 + Vrms2² × Δt2 + …) / T ]
Vav  = (波形面積和) / T      ← 面積有正有負要相減
```

**交直流混波**：`Vrms = √( Vdc² + Vac(rms)² )`，平均值 = 直流項
- 例：v = 4 + 3√2 sin ωt → Vrms = √(4² + 3²) = **5 V**，Vav = 4 V

**兩個同頻率正弦相加**（Vm 相同時）：相位差 60° → ×√3；90° → ×√2；120° → ×1；新相角取平均。

## Ch2 二極體及應用電路

### 2-1 半導體材料 ⭐
- 半導體：導電性介於**導體與絕緣體**之間；常溫下幾乎絕緣，要加電壓才導通 → 導電性**可以控制**。
- **元素半導體**：矽 Si、鍺 Ge（**四價**）；**化合物半導體**：砷化鎵 GaAs、氮化鎵 GaN（III-V 價）、硫化鎘 CdS（II-VI 價）

| 世代（老師補充） | 材料 | 能隙 | 特色 |
|---|---|---|---|
| 第一代 | 矽 Si | 1.1 eV | 最常用 |
| 第二代 | 砷化鎵 GaAs | 1.43 eV | 電子移動率快 → 高頻、高功率電晶體 |
| 第三代 | 碳化矽 SiC、氮化鎵 GaN | 3.2、3.4 eV | **寬能隙**；耐高溫、高壓、高電流，高頻也穩定 → 電動車、5G、軍用雷達 |

- 電子分類：**束縛電子**（內層，被原子核綁住）、**價電子**（最外層）、**自由電子**
- 電子層：K、L、M、N 最多 2、8、18、32 個（2n²）；矽 = 2 + 8 + **4**
- 能量單位：**電子伏特 eV**
- 能隙 Eg = Ec − Ev（傳導帶 − 價電帶，中間叫**禁止帶**）

| 種類 | 能隙 | 例子 |
|---|---|---|
| 導體 | ≤ 0 eV | 金、銀、銅 |
| 半導體 | ≈ 1 eV | **矽 1.12 eV、鍺 0.66 eV** ⭐ |
| 絕緣體 | ≥ 9 eV | 木頭、玻璃 |

- **共價鍵**：相鄰原子共用一組電子對（八隅體學說：最外層 8 個電子最穩定）；矽、鍺為**鑽石型**晶體結構
- 0 K：共價鍵不被破壞 → 不導電；室溫 300 K（27 °C）：共價鍵可能斷裂 → 產生電子電洞對

### 本質 vs 外質半導體 ⭐⭐
- **本質半導體**：純矽 / 純鍺，**沒有摻雜**，導電性極差；溫度上升 → 共價鍵斷裂 → 產生**電子電洞對**
- 質量作用定律：**nᵢ² = n × p**；本質半導體 **nᵢ = n = p**
- 熱平衡時半導體呈**電中性**
- 一般說的「電流」指的是**電洞流**（與電子流方向相反）
- **外質半導體**（雜質半導體）：**摻雜 (doping)** 提高導電性，比例約 **矽 : 雜質 = 10⁸ : 1**
  - 摻雜後仍是**電中性**（雜質原子本身是電中性的）⭐
  - 摻雜 ↑ → 電阻 ↓、導電能力 ↑、耐壓 ↓

| | P 型 | N 型 |
|---|---|---|
| 摻雜 | **三價**：硼 B、鋁 Al、鎵 Ga、銦 In | **五價**：磷 P、砷 As、銻 Sb、鉍 Bi |
| 結果 | 共價鍵多一個**空位**（電洞） | 多一個不受束縛的**電子** |
| 多數載子 | **電洞** | **電子** |
| 少數載子 | 電子 | 電洞 |
| 雜質名稱 | **受體** acceptor（接受電子） | **施體** donor（施放電子） |

記法：**P 三受洞、N 五施電**。

**溫度係數**（老師補充）
- **正溫度係數**：T↑ → R↑（金屬導體、高摻雜半導體；課本：外質半導體變成正溫度係數材料）
- **負溫度係數**：T↑ → R↓（本質 / 低摻雜半導體、絕緣體；因為電子電洞對變多）

### 2-2 P-N 接面二極體 ⭐⭐
- 特性：**整流、檢波、單向導通**（**不能放大**）
- 符號：A（陽極，P 型）→ K（陰極，N 型），箭頭 = 電流方向
- **擴散電流 I_F**：多數載子因**濃度差**移動，P → N
- **漂移電流 I_S**：少數載子受空乏區**電場**影響，N → P
- **空乏區**：接面附近沒有可移動載子；P 側帶負電、N 側帶正電；電場方向 **N → P**
- 空乏區偏向**摻雜濃度較低**的一側（較寬）

| 狀態 | 接法 | 空乏區 | 電流 |
|---|---|---|---|
| 未偏壓 | — | 固定 | I_F = I_S，I_D = 0 |
| **順偏** | **P 接 +、N 接 −** | **變窄** | I_D = I_F − I_S（很大）→ 導通 |
| **逆偏** | P 接 −、N 接 + | **變寬** | I_F = 0，I_D = −I_S（極小）→ 截止 |
| 崩潰 | 逆偏 > V_BR | 佈滿 | 電流暴增，可能燒毀（串電阻限流） |

- **障壁電壓 / 切入電壓 Vt**（膝點電壓）：**鍺 0.2–0.3 V、矽 0.6–0.7 V** ⭐
- 逆向飽和電流 I_S：**矽 ≈ nA、鍺 ≈ μA**；矽 V_BR 可達約 1000 V
- 矽：漏電流小、耐高溫、便宜；鍺：漏電流大
- 二極體電流公式：**I_D = I_S (e^(V_D/ηV_T) − 1)**
  - V_T 熱當電壓 ≈ **25–26 mV**；η：**鍺 = 1、矽 = 2**

### 溫度特性 ⭐⭐（計算題）

```
I_S(T2) = I_S(T1) × 2^[(T2 − T1)/10]      ← 每升 10°C，漏電流變 2 倍
Vt(T2)  = Vt(T1) − 2.5mV × (T2 − T1)      ← 每升 1°C，切入電壓降 2.5 mV
```
- 溫度 ↑ → 曲線往內（往 Y 軸）靠

### 二極體電阻 ⭐

| 名稱 | 公式 | 用途 |
|---|---|---|
| 直流靜態電阻 | **R_D = V_DQ / I_DQ** | 直流 |
| 交流動態電阻 | **r_d = ΔV_D / ΔI_D = ηV_T / I_DQ** | 交流（曲線斜率的倒數） |
| 順向導通電阻 | **R_F = (V_DQ − Vt) / I_DQ** | 近似模型 |

### 二極體電容 ⭐

| | 空乏電容（過渡電容、接面電容） C_T | 擴散電容（儲存電容） C_D |
|---|---|---|
| 公式 | **C_T = ε A / W** | **C_D = τ I_F / (ηV_T)** |
| 大小 | pF | μF |
| 關係 | 與空乏區寬度 **W 成反比**；逆偏 ↑ → W ↑ → **C_T ↓** | 與擴散電流 **成正比**；與平均壽命 τ 成正比；順偏 ↑ → **C_D ↑** |

- 順偏：**C_F = C_T + C_D**；逆偏：**C_R = C_T**
- 逆偏時**沒有**擴散電容

### 二極體等效模型 ⭐⭐

| 模型 | 順偏 | 逆偏 |
|---|---|---|
| 理想 | V_D ≥ 0 → **短路** | **開路** |
| 定電壓 | V_D ≥ Vt → **電池 Vt** | 開路 |
| 近似（線性） | **電池 Vt 串 R_F** | 開路 |

**解題步驟（老師：重要題型！）** ⭐⭐⭐
1. 先把二極體**拿掉（開路）**
2. 算二極體兩端的開路電壓 V_th（通常用分壓）
3. V_th ≥ Vt → 二極體導通，換成 Vt 電池（或 Vt + R_F）再算；V_th < Vt → 二極體開路

**多顆二極體（OR 閘型）**：假設所有 ON/OFF 組合，只有一組不矛盾。陽極接在一起時，**輸入最高的那顆導通**；陰極接在一起（往下拉）時，**電位最低的那顆導通**。

### 2-3 稽納二極體 ⭐⭐
- **高摻雜**（約 10⁵ : 1），工作在**逆向偏壓**，用途：**穩壓**
- 順偏時跟一般二極體一樣（0.7 V）
- 逆偏 |E| ≥ V_Z → 當作**定電壓源 V_Z**（近似模型再串 R_Z）；|E| < V_Z → **開路**
- 符號：K 端有「Z 字」折線

| | 稽納崩潰 | 累增崩潰 |
|---|---|---|
| 電壓 | **< 6 V** | **> 6 V** |
| 濃度 / 空乏區 | 濃度高、空乏區**窄** | 濃度低、空乏區**寬** |
| 原因 | **電場**效應 | **熱擾動**、載子撞擊 |
| 溫度係數 | **負**（崩潰電壓隨溫度上升而減少） | **正** |
| 可逆？ | **可逆** | **不可逆** |

- **I_ZK 膝點電流**：稽納崩潰的**最小**電流；**I_ZM** 最大電流 = **P_Z / V_Z**
- V_Z 一般約 3–5 V，最高可到 100 V
- 解題方法同一般二極體：先拿掉稽納 → 算開路電壓 → ≥ V_Z 就換成 V_Z 電池
- 負載範圍題：I = I_Z + I_L；I_Z ≤ I_ZM → 求 R_L 最大；I_Z ≥ 0（或 I_ZK）→ 求 R_L 最小

### 2-4 發光二極體 LED ⭐
- 工作在**順向偏壓**；**電流越大越亮**（電流與發光強度成正比）
- 優點：消耗功率低、工作溫度低、壽命長、耐摔、切換速度快；**冷性發光**
- 發光原理：電子電洞**復合**時，多餘能量以**光子**釋放（輻射復合）；以聲子釋放則不發光
- **直接能隙**（GaAs、GaN）→ 發光效率**高**，做 LED；**間接能隙**（Si、Ge）→ 發光效率**低**
- 顏色由**材料**決定

| 材料 | 顏色 | 切入電壓 | 波長 |
|---|---|---|---|
| GaAs 砷化鎵 | 紅外線（不可見） | 1–1.9 V | > 760 nm |
| AlGaAs 鋁砷化鎵 | 紅 | 1.6–2 V | 760–610 nm |
| GaAsP 砷化鎵磷 | 黃 | 2.1 V | 590–570 nm |
| GaP 磷化鎵 | 綠 | 2–3 V | 570–500 nm |
| SiC 碳化矽 | 藍 | 3–5 V | 500–450 nm |

- 常用 LED 切入電壓 **1.7–3.3 V**；逆向崩潰電壓 **5–10 V**（比一般二極體小）
- 可見光 **380–760 nm**，人眼對 **555 nm** 最靈敏；紅外線 760 nm–1 mm（遙控器）；紫外線 < 380 nm
- 符號：箭頭**往外射出**（光電二極體是箭頭往內）
- 限流電阻：**R = (E − n·V_F) / I_F**

### 2-5 整流濾波電路 ⭐⭐⭐
**電源方塊**：110V/60Hz → **變壓器**（降壓）→ **整流**（變脈動直流）→ **濾波**（漣波變小）→ **穩壓**（純直流）

**變壓器**（理想，P₁ = P₂，效率 100%）
```
V1/V2 = N1/N2          （電壓與匝數成正比）
I2/I1 = N1/N2          （電流與匝數成反比）
R1/R2 = (N1/N2)²       （阻抗與匝數平方成正比）
最大功率轉移：R_S = R1
```

**整流電路比較表** ⭐⭐⭐（必背）

| 電路 | 二極體數 | 每顆 PIV | f_o | Vo(rms) | Vo(av) |
|---|---|---|---|---|---|
| 半波 | 1 | **Vm** | **f_i** | **Vm/2** | **Vm/π = 0.318Vm** |
| 中心抽頭全波 | 2 | **2Vm** | **2f_i** | Vm/√2 | 2Vm/π = 0.636Vm |
| 橋式全波 | 4 | **Vm** | **2f_i** | Vm/√2 | 2Vm/π = 0.636Vm |

- **PIV 逆向峰值電壓**：二極體需要的最小耐壓，|V_BR| > |PIV|
- 半波：Vdc = 0.45 V_AC（rms）
- 橋式：D₁D₃ 管正半週、D₂D₄ 管負半週；對邊二極體方向要一致
- **加了電容濾波後的 PIV**：半波 **2Vm**、中心抽頭 2Vm、橋式 Vm

**電表題（範例 2-9）**：表頭讀平均值、刻度用有效值顯示（正弦波設計）
- 半波整流：倍率 = 0.707/0.318 ≈ **2.22** → 輸入 DC 10 V 顯示 **22.2 V**
- 全波整流：倍率 = 0.707/0.636 ≈ **1.11** → 顯示 **11.1 V**

### 濾波與漣波 ⭐⭐
- 最常用的濾波元件是**電容**（電容越大，濾波效果越好）
- 純電容濾波：**無負載時 Vo(dc) = Vm**；接負載後產生漣波
- 動作：輸入 > 電容電壓 → 二極體導通、電容**快充**；輸入 < 電容電壓 → 二極體截止、電容對 R_L **慢放**
- RC ↑ → 放電慢 → 漣波 ↓

```
漣波因數 r = Vr(rms) / Vo(dc)        （越小越好，理想 = 0）
Vdc = Vm − Vr(p-p)/2
Vr(rms) = Vr(p-p) / (2√3)             （漣波近似三角/鋸齒波）
Vr(p-p) = Idc / (C × fo)               Idc = Vdc / R_L
fo：半波 = f_i、全波 = 2f_i
r = 1 / (2√3 R_L C fo)
```
- 60 Hz 時（**R_L 用 kΩ、C 用 μF**）：**半波 r ≈ 4.8/(R_L C)**、**全波 r ≈ 2.4/(R_L C)**
- 沒濾波的漣波：**半波 Vr(rms) = 0.385Vm、r = 1.21（121%）**；**全波 Vr(rms) = 0.308Vm、r = 0.48（48%）**
- 混波 v = 6 + 3√2 sin ωt → Vr(rms) = 3，r = 3/6 = **50%**
- 半波整流的 C.F. = 2、F.F. = 1.57、r = 1.21 → **C.F. > F.F. > r**

**整流濾波電路表（f_i = 60 Hz，R_L 用 kΩ、C 用 μF）**

| 電路 | PIV | f_o | Vr(rms) | r |
|---|---|---|---|---|
| 半波整流濾波 | 2Vm | 60 Hz | 4.8 Vdc / (R_L C) | 4.8 / (R_L C) |
| 中心抽頭全波濾波 | 2Vm | 120 Hz | 2.4 Vdc / (R_L C) | 2.4 / (R_L C) |
| 橋式全波濾波 | Vm | 120 Hz | 2.4 Vdc / (R_L C) | 2.4 / (R_L C) |

### 2-5-6 時間常數 R_L C 與漣波
- R_L C < T（C 小）→ 放電快 → **漣波大**
- R_L C ≫ T（C 大）→ 漣波小
- **R_L 開路（= ∞）** → 電容不放電 → **沒有漣波，Vo = Vm**，r = 0（最理想）

### 2-5-7 其他濾波電路 ⭐（都是**低通濾波器**）

| 濾波器 | 結構 | 適用 | 備註 |
|---|---|---|---|
| RC（π 型 CRC） | C₁ − R − C₂ | **輕負載**（R_L 大、電流小） | R 會分壓，直流電壓下降 |
| **π 型** | C₁ − L − C₂ | R_L 小也好 | **效果最好**（但成本高）；L 不會讓直流壓降 |
| 純電感 | 串一個 L | **重負載**（R_L 小、電流大） | **只能接全波**；Vdc 最高 0.636Vm |
| LC | L 串、C 並 | 重負載 | 只能接全波；Vdc 最高 0.636Vm |
| T 型（LCL） | L₁ − C − L₂ | 重負載 | 只能接全波 |

記法：**有電阻 / 電容先接 → 輕負載；電感先接 → 重負載、只能全波**。

### 2-6 稽納穩壓電路 ⭐⭐
- 在濾波電路輸出端**並接稽納二極體**（串 R_S 限流），得到更穩的直流
- 用**重疊定理**分成直流與交流分析，最後 **V_L(總) = V_L(直流) + v_L(交流)**

**直流分析**（稽納看成 V_Z 電池）
- DC × R_L/(R_S + R_L) **≥ V_Z** → 稽納崩潰，**V_L = V_Z**
- 否則稽納開路，**V_L = DC × R_L/(R_S + R_L)**
- 若有內阻 r_Z：稽納 = V_Z 電池串 r_Z，用節點電壓法解

**交流分析**（稽納看成電阻 r_Z = ΔV_Z / ΔI_Z）
```
v_L = AC × (R_L // r_Z) / [ r_S + (R_L // r_Z) ]
```

**範例 2-12 類型**：E = 15 V、R = R_L = 30 Ω、V_Z = 5 V、r_Z = 10 Ω
- 節點：(V − 15)/30 + (V − 5)/10 + V/30 = 0 → **V_L = 6 V**
- I_Z = (6 − 5)/10 = 0.1 A；**P_Z = V_Z I_Z + I_Z² r_Z = 0.5 + 0.1 = 0.6 W**
- ΔE = 10 mV → ΔV_L = 10m × (30//10)/(30 + 30//10) = 10m × 7.5/37.5 = **2 mV**

**電壓調整率 VR%** ⭐⭐
```
VR% = (V_NL − V_FL) / V_FL × 100%
```
- V_NL 無載電壓（拿掉負載，R_L = ∞）；V_FL 滿載電壓（接上負載）
- **越小越好，理想 VR% = 0**
- 也等於「電源內阻電壓 ÷ 負載電壓」
- 理想**電壓源內阻 = 0**；理想**電流源內阻 = ∞**

**為什麼稽納多拿來當參考電壓，而不是穩壓元件？** 可選的電壓值有限、最大電流太小容易燒毀（I_Z 太大 → P_Z 太大）、是被動元件，會受負載影響。

### 矽 vs 鍺二極體（本章摘要表）⭐

| | 矽 | 鍺 |
|---|---|---|

## Ch3 雙極性接面電晶體 (BJT)

### 3-1 構造 ⭐
- BJT（bipolar junction transistor），**主動元件**，可做**放大**與**開關**；1947 年貝爾實驗室。
- 分 **NPN** 與 **PNP**，三極：**射極 E、基極 B、集極 C**
- 兩個接面：**J_E（B-E 接面）**、**J_C（B-C 接面）**
- 功能：**E 發射**多數載子、**B 控制**載子數量、**C 收集**載子
- ⭐ **摻雜濃度：E > B > C**
- ⭐ **寬度（體積）：C > E > B**（B 約為整體的 1/150；C 最大，與外殼相接散熱用）
- 符號箭頭＝電流方向（P 指向 N）：NPN 箭頭朝外（B→E），PNP 箭頭朝內（E→B）
- 多數載子：NPN = 電子、PNP = 電洞
- 電流同時含電子流與電洞流 → 又稱**雙載子元件**

### 四種工作模式 ⭐⭐⭐（一定考）

| 模式 | B-E 接面 J_E | B-C 接面 J_C | 功能 |
|---|---|---|---|
| **順向主動區**（作用區 / 工作區） | **順偏** | **逆偏** | **放大** |
| **飽和區** | 順偏 | 順偏 | 開關 **ON** |
| **截止區** | 逆偏 | 逆偏 | 開關 **OFF** |
| 逆向主動區 | 逆偏 | 順偏 | 邏輯交換電路（增益下降） |

口訣：**「射順集逆 → 放大」**；兩個都順 → 飽和；兩個都逆 → 截止。

**電壓大小關係（NPN；PNP 全部反過來）**

| 模式 | NPN | PNP |
|---|---|---|
| 主動區 | V_C > V_B > V_E | V_E > V_B > V_C |
| 飽和區（實際電路） | V_B > V_C > V_E | V_E > V_C > V_B |
| 截止區（實際電路） | V_C > V_E > V_B | V_B > V_E > V_C |

**判斷工作區的步驟（矽晶體）**：
1. NPN 算 V_BE = V_B − V_E；PNP 算 V_EB = V_E − V_B。**≥ 0.7 V → B-E 順偏**
2. NPN 算 V_BC = V_B − V_C；PNP 算 V_CB = V_C − V_B。**> 0.5 V → B-C 順偏**

**各區特性**
- 主動區：**I_E = I_C + I_B**，I_E > I_C > I_B（I_E ≈ I_C ≫ I_B）；**I_C = βI_B = αI_E**；V_CE > 0.2 V
- 飽和區：**V_CE(sat) ≈ 0.2 V**（= V_CB(t) − V_EB(t) = −0.5 − (−0.7)），C-E 視為**短路**，I_C = I_C(sat) 由外部電路決定；I_B 越大 β_S 越小

### 獨立源 vs 相依源
- **獨立**電源：不受迴路影響（圓形符號）
- **相依**電源：受其他電壓 / 電流控制（**菱形**符號）

### 電流增益 ⭐⭐⭐

```
α = I_C / I_E      （< 1，約 0.99）
β = I_C / I_B      （幾十 ~ 幾百）
γ = I_E / I_B

γ = 1 + β = 1/(1 − α)
α = β / (1 + β)
β = α / (1 − α)
I_E = (1 + β) I_B
```

### 漏電流
- I_CO（= I_CBO）：B-C 接面逆偏的漏電流（少數載子造成）
- **I_CEO = (1 + β) I_CBO**（B 開路時 C→E 的總漏電流）
- **I_C = βI_B + I_CEO**；I_E = (1 + β)I_B + I_CEO
- NPN、PNP 漏電流方向與主電流方向一致

### 功率
- **P_Q = I_C × V_CE** ⭐

### 3-2 三種組態 ⭐⭐

| 組態 | 輸入 | 共用 | 輸出 | 電流增益 |
|---|---|---|---|---|
| 共基極 CB | E | **B** | C | **α** |
| 共射極 CE | B | **E** | C | **β** |
| 共集極 CC | B | **C** | E | **γ** |

- ⭐ **C 極不能當輸入，B 極不能當輸出**
- 電流增益：**CC > CE > CB**（γ > β > α）
- 名稱看「共用端」是哪一極

**特性曲線（X 軸、Y 軸常考）**

| 組態 | 輸入曲線 | 輸出曲線 | 飽和分界 |
|---|---|---|---|
| CB | X：V_BE，Y：I_E | X：V_CB，Y：I_C（不同 I_E） | V_CB ≤ −0.5 V 飽和 |
| CE | X：V_BE，Y：I_B | X：V_CE，Y：I_C（不同 I_B） | V_CE ≤ 0.2 V 飽和 |
| CC | X：V_BE，Y：I_B | X：V_EC，Y：I_E（不同 I_B） | V_EC ≥ −0.2 V 飽和 |

- 輸入曲線都像二極體：V_BE ≤ 0.7 V → 截止區

**迴路方程式**

- CE：**V_BB = I_B R_B + V_BE**；**V_CC = I_C R_C + V_CE** ⭐
- CC：V_BB + V_EE = I_B R_B + V_BE + I_E R_E；V_EE = V_CE + I_E R_E
