  • 加了電容以後，半波的 PIV 從 Vm 變成 2Vm；中心抽頭還是 2Vm，只剩橋式是 Vm。

  • 0.0048 是 RL 用 Ω、C 用 F；如果 RL 用 kΩ、C 用 μF，就是 4.8 和 2.4。

電晶體工作模式

16 格
工作模式B-C 接面B-E 接面NPN 電晶體PNP 電晶體
順向主動區逆向偏壓順向偏壓VC > VB > VEVC < VB < VE
飽和區順向偏壓順向偏壓VB > VC > VEVB < VC < VE
截止區逆向偏壓逆向偏壓VC > VE > VBVC < VE < VB
逆向主動區順向偏壓逆向偏壓VE > VB > VCVE < VB < VC
怎麼記
  • ⚠️ 這張表是 B-C 在前、B-E 在後，跟平常講「射順集逆」的順序相反。順向主動區要填「逆向、順向」。
  • 偏壓：飽和「兩個順」、截止「兩個逆」、逆向主動跟順向主動相反。
  • NPN：主動區照字母 C > B > E；飽和 B 最大；截止 B 最小；逆向主動是主動倒過來 E > B > C。
  • PNP = 把 NPN 的「>」全部改成「<」，字母順序完全不動。

電晶體放大電路組態表

12 格
工作組態輸入端共用端輸出端電流增益比
共基極 (CB)E 極B 極C 極α = ICIE
共射極 (CE)B 極E 極C 極β = ICIB
共集極 (CC)B 極C 極E 極γ = IEIB
怎麼記
  • 共用端 = 名字的第二個字母：CB 共 B、CE 共 E、CC 共 C。
  • 剩下兩極用「C 不能當輸入、B 不能當輸出」排：CB → E 入 C 出；CE → B 入 C 出；CC → B 入 E 出。
  • 電流增益 = 輸出電流 ÷ 輸入電流：CB 是 IC/IE、CE 是 IC/IB、CC 是 IE/IB。
  • 順便背（摘要 10）：γ = 1 + β、α = β/(1 + β)、β = α/(1 − α)、γ = 1/(1 − α)；大小 γ > β > α。
